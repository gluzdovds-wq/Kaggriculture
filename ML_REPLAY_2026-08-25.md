# Public-replay ML pilot — 2026-08-25

## Outcome

The useful first model is **factorized**, not one flat action classifier:

1. A route/archetype head tests whether the opponent's broad policy family is
   inferable from early public state.
2. Binary event gates predict whether a high-impact market event occurs during
   the next 24 turns.
3. A conditional `COW / SHEEP / MIX` head runs only when the animal-buy gate is
   active.

The route head failed the transfer gate and must not control the live agent.
The event and animal heads are retained as offline proposal models.  They
imitate current top-bot behavior; they do not yet estimate which intervention
maximizes our match outcome.

## Corpus and leakage contract

- Source: 74 unique current public episodes, 2,310,683,468 replay bytes.
- Coverage: eight requested games for each current top-ten submission plus S20
  and S21 controls; shared pairings produced 96 target-player seasons from 12
  complete submission policies.
- Compact outputs: 96 full-season policy rows, 288 day-3/6/9 public checkpoint
  rows, and 2,784 public day-start event rows.
- Model features contain both public farms, shared market state and visible
  shops.  Opponent-private shed, seeds and unit inventories are excluded.
- Every evaluation fold holds out one complete submission policy.  No rows or
  episodes from that policy appear in its training fold.

Raw replays, compact datasets and fitted weights remain under ignored
`artifacts/` because competition replay data must not be redistributed.

## Architecture results

Unsupervised route discovery found only two stable policy groups: two
high-WHEAT-sale policies versus ten lower-WHEAT-sale policies.  The best early
checkpoint was day 6, but policy-held balanced accuracy was only `0.500`
(`0.750` ordinary accuracy), so the head mostly learned the dominant class.
There is no evidence for a deployable broad route router in this corpus.

For the conditional animal choice, independent one-vs-rest GBDTs beat one
joint multiclass GBDT on the exact same policy-held folds:

- direct multiclass: accuracy `0.7552`, balanced accuracy `0.5772`, log-loss
  `0.3742`;
- one-vs-rest: accuracy `0.8759`, balanced accuracy `0.7213`, log-loss
  `0.3502`.

The three `GOOSE` rows came from one policy only and were excluded from this
head because a complete-policy holdout cannot evaluate that class.

The high-precision binary gates performed as follows:

- buy land: precision `0.9272`, recall `0.7292`, balanced accuracy `0.8625`;
- buy animal: precision `0.9375`, recall `0.7976`, balanced accuracy `0.8918`;
- sell fertilizer: precision `0.9774`, recall `0.9766`, balanced accuracy
  `0.8799`;
- sell premium products: precision `0.9936`, recall `0.9794`, balanced accuracy
  `0.9830`.

All four beat a policy-held day-only schedule.  The largest gain in average
precision was land timing (`+0.2090`), followed by animal buying (`+0.0903`).
Fertilizer and premium-sale labels are already highly calendar-driven, so their
incremental average-precision gains were only `+0.0101` and `+0.0026`.

## Reproduction

```powershell
python -m pip install -r requirements-ml.txt
python tools\collect_top_replays.py `
  --leaderboard research\top10_leaderboard_2026-08-25.json `
  --output-dir artifacts\kaggle_episodes\top10-il-2026-08-25 `
  --manifest artifacts\top10-il-replay-manifest-2026-08-25.json `
  --per-agent 8
python -m rl.build_public_replay_ml_dataset `
  --manifest artifacts\top10-il-replay-manifest-2026-08-25.json `
  --output-dir artifacts\public_replay_ml_2026-08-25
python -m rl.train_public_replay_gbdt `
  --dataset-dir artifacts\public_replay_ml_2026-08-25 `
  --output-dir artifacts\public_replay_gbdt_2026-08-25
```

The complete fitted bundle is
`artifacts/public_replay_gbdt_2026-08-25/public_replay_gbdt.joblib` (864,806
bytes); the full policy-held metrics are in the adjacent
`training_report.json`.

## Next promotion gate

The next dataset must carry **counterfactual outcome labels**, not merely donor
actions.  At a shared public checkpoint, keep the strong Shop Guard continuation
as an explicit action and evaluate a small set of bounded alternatives on the
same replay/seed/seat.  Train the router on outcome first and clipped margin
second.  Only a distilled pure-Python gate with zero outcome regression across
the adaptive local league is eligible for integration or a later two-bot live
batch.
